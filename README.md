# 🏡 HouseVal Ai

A machine learning web application that predicts estimated house prices based on property features. Built as a portfolio project to demonstrate end-to-end ML deployment.

## 🚀 Features
* Predicts market value based on property details and features.
* Interactive web user interface built with **Streamlit**.
* Powered by a trained regression model using **Scikit-Learn** and **Pandas**.

## 🛠️ Tech Stack
* **Python**
* **Streamlit**
* **Scikit-Learn**
* **Pandas**
